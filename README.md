## Introduction

Welcome to Chirper's official desktop overlay. This app allows users to post and interact with other Chirps across different servers, all from one intuitive overlay. Posts, replies, likes, reposts, and more all sync directly to the Discord server you're using with the app, just as they do with the Discord bot.

### Features

- An always-on-top overlay, great for Roblox games, that can be toggled with a small Chirper icon
- Chirper Internet, Marketplace, and Dark Web, all available directly on the phone
- A camera that can be used to take screen captures of different windows, such as Roblox, and attach them directly to posts
- Live synchronization with Discord that matches the experience of the Discord bot

## Installation

To get started, select the correct installation package below:

- [**macOS ARM64**](https://github.com/ChirperApp/desktop/releases/latest/download/chirper-macos-arm64.dmg) — select this if you have an M-series Mac, including M1, M2, M3, M4, or M5
- [**macOS x64**](https://github.com/ChirperApp/desktop/releases/latest/download/chirper-macos-x64.dmg) — select this if you have an older Intel-based Mac
- [**Windows**](https://github.com/ChirperApp/desktop/releases/latest/download/chirper-windows.exe) — select this if you have a Windows laptop or PC

Linux and other operating systems are not supported at this time.

**[View the latest release](https://github.com/ChirperApp/desktop/releases/latest/)**

Once you've downloaded the installer, follow the installation instructions. Windows Defender may flag the app as malicious. If this occurs, select `More info`, then `Run anyway`.

### Is the app safe? Can I view the source code first?

To protect the integrity of Chirper's software, **the source code is not publicly available**. However, the app only requests the minimum permissions required to operate, and elevated permissions, such as Screen Recording, are only required to use the Camera feature.

If you're still uncomfortable installing the app, all features are available through our Discord bot's slash commands.
